# Silo brand attribution

The unmodified `silo-wordmark-white.png` is the official 1544 × 800 PNG from
[Silo's brand assets](https://siloserver.org/brand), downloaded from
https://siloserver.org/brand/silo-wordmark-white.png on 2026-10-15.
Copyright © 2026 Silo Media L.L.C. See [NOTICE.txt](NOTICE.txt).

The Roku app uses this official wordmark for its Silo presentation, as requested
by the project owner. The white wordmark appears on a
dark field, with the supplied aspect ratio and padding preserved through
`scaleToFit`; the artwork is not cropped, recolored, or redrawn.

Follow the [usage guide](https://siloserver.org/brand) and
[trademark policy](https://github.com/Silo-Server/siloserver.org/blob/main/TRADEMARK.md)
for future changes or distribution.


Launch artwork also uses the official vector masters `silo-app-icon.svg` and
`silo-wordmark-white.svg`, downloaded from the same brand directory on 2026-10-15.
`python3 tools/generate_assets.py` exports the original vectors through librsvg
(`rsvg-convert`), preserving proportions and full artwork. The app icon is
centered in Roku's landscape tile; the startup wordmark is centered on black.
There is no replacement typesetting, crop or recoloring. Pillow remains required
only for the existing native focus bitmap generated by that tool.
